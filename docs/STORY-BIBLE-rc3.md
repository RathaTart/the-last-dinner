# เรื่องจริงของคืนสุดท้าย — สำหรับผู้พัฒนา (มีเฉลย)

ฉบับ 1 ตุลาคม 2026

**ประเด็น:** คนในครอบครัวจำสิ่งที่รับรู้ได้ไม่ครบ และปล่อยข้อสรุปที่ไม่ได้ตรวจสอบให้กลายเป็นเรื่องจริงร่วมกัน ผู้เล่นแก้ข้อเท็จจริงได้ แต่ไม่สามารถบังคับให้ใครให้อภัย

## Knowledge matrix

- อรุณ: เห็นซอง ได้ยินคำรับผิด แต่ไม่เห็นการหยิบ/การใช้เงิน ไม่รู้ตำแหน่งปัจจุบันมีรา
- ลิน: รู้ผู้หยิบ เหตุผล เวลาในคลินิก และการส่งซอง รู้สึกผิด แต่ไม่รู้ว่ามีราอยู่ที่ไหนตอนนี้
- ป้าละไม: รู้เวลาอาหาร เห็นซอง ไม่รู้ค่ารักษา; รู้ที่พักคืนแรกและกระเป๋า ไม่รู้ที่อยู่ปัจจุบัน
- ผู้เล่น: เริ่มจากข้อกล่าวหาของครอบครัว แยก observation กับ testimony ก่อนสรุป
- LLM: รับเฉพาะข้อเท็จจริงที่เปิดเผยได้ต่อ NPC ไม่ได้รับ client identity หรือบทจบ

## Evidence graph

```text
ป้ายซ่อม + ระฆัง → แก้เวลา → คำพูดหลังระฆัง
จดหมายไม่ระบุเหตุ + คลินิก/ชื่อผู้จ่าย + ซองว่าง → ลินใช้เงินรักษาสุนัข
สมุดอาหาร + ใบเสร็จ/การส่งซอง → ใช้เงินก่อนมีราออก
คำรับผิด + คำไล่ + ความทรงจำกระเป๋า → มีรารับผิดแทนลินและเลือกออกไปพัก
ข้อเท็จจริงครบ → ประกอบเวลา → สรุป → เผยผู้ว่าจ้าง → เตรียมแนวทางบอกความจริง
```

## หลักของงานภาพ/เสียง

บ้านปัจจุบัน: teal/ไม้/ทอง แสงเย็นที่ยังอบอุ่น ความทรงจำ: mint/ม่วงซีด ฉากที่ถูกจำไม่ชัดไม่เพิ่มเหตุการณ์ใหม่ ตัวละครทำกิจวัตรผ่าน animation ที่เขียนไว้ ปริศนาไม่มีข้อมูลที่ได้เฉพาะผ่านเสียง ดนตรีสังเคราะห์เดิมใช้ motif ที่วนและเปลี่ยน pitch เมื่อเข้าสู่อดีต

ให้คนใหม่อธิบายว่าเหตุใดมีราขาดการติดต่อ และรู้สึกอย่างไรกับการที่ครอบครัวปล่อยความเงียบอยู่ห้าปี หากเหตุผลไม่ชัด ให้เพิ่มบทที่เปิดเผยหลังหลักฐาน ไม่เพิ่มหลักฐานที่เฉลยก่อนเวลา ไม่ถือว่าการทดสอบอัตโนมัติแทนการวัดอารมณ์ได้
