# ผังคฤหาสน์และมาตรฐานฉาก — rc.5

บ้านที่ผู้เล่นอ่านทางได้ มีเหตุผลว่าจะใช้แต่ละพื้นที่อย่างไร และมีรายละเอียดที่ช่วยสืบคดี คือเป้าหมายของผังนี้ ภาพใช้ตัวละครแบบ stylized กับฉาก Three.js บนเว็บ งานรอบนี้เพิ่มความสมจริงของพื้นที่และวัสดุ ส่วนโมเดลเฉพาะเกม งานเสียง และการทดสอบผู้เล่นเป็นขั้นผลิตถัดไป

## ขนาดและแหล่งข้อมูลเดียว

พื้นที่แต่ละระดับประมาณ **24 × 19 เมตร**; x ตั้งแต่ −12 ถึง +12, z ตั้งแต่ −9.5 ถึง +9.5 ประตูหน้าอยู่ทาง +z ด้านหลังบ้านอยู่ทาง −z ชั้นล่างสูง 0 เมตร ชั้นสอง +4.4 และใต้ดิน −4.4 ผังนี้เป็นคฤหาสน์กว้าง ไม่ใช่บ้านพักขนาดเล็ก ขนาดระบุพื้นที่ผังรวมซึ่งยังไม่ได้หักผนังและช่องบันได

`mansion-layout.js` ระบุขอบเขต 14 ห้อง ผนัง ประตู เฟอร์นิเจอร์ ตำแหน่งหลักฐาน จุดเกิด กิจวัตร NPC และทางขึ้นลง `navigation.js` ใช้ข้อมูลชุดนี้ตรวจ collision; `mansion-environment.js` ใช้สร้างฉาก ประตูจึงเป็นช่องจริงในผนัง ไม่ใช่สัญลักษณ์ทับกำแพงทึบ

## ทางสัญจรที่อธิบายเรื่องได้

เส้นทางรับแขกคือ **ประตูหน้า → โถงรับแขก → โถงใหญ่ → ห้องอาหารหรือห้องดนตรี** ส่วนห้องงานกับครัวอยู่ปีกหลัง ประตูเสิร์ฟระหว่างครัวกับห้องอาหารช่วยให้กิจวัตรแม่ครัวมีเหตุผล แทนการพาอาหารผ่านโต๊ะช่าง

**บันไดใหญ่** เชื่อมโถงใหญ่กับชานพักชั้นสอง **บันไดรับใช้** เชื่อมครัวกับโถงใต้ดิน ตำแหน่งทั้งสองแยกกันให้ผู้เล่นรู้ว่ากำลังเข้าเขตบ้านหรือเขตบริการ รุ่นนี้ขึ้นลงด้วยการเดินเข้าใกล้แล้วกด E; ยังไม่ได้จำลองเดินตามขั้นพร้อมความสูงของตัวละคร

ห้องลับมีประตูเดียวทางห้องเตา ไม่มีช่องผ่านจากโถงใต้ดิน การเปิดต้องอาศัยคำให้การสองคนและรหัส เป็นการเปลี่ยนทางเข้าของฉากจริง ไม่ใช่เพียงเปิดบัตรหลักฐานใน UI คำตอบผิดแก้ได้และไม่ลบหลักฐาน

## มาตรฐานที่ตรวจได้

- **ทางเดิน:** ผนังมีช่องประตูกว้าง 1.8–2.8 เมตร; รัศมีตัวผู้เล่น 0.2 เมตร ขนาดนี้เป็นหน่วยเล่นเกม ไม่ใช่การรับรองแบบก่อสร้าง
- **หลักฐาน:** ของจริงทั้งแปดจุดมีเส้นทางเข้าใกล้ระยะโต้ตอบ 1.65 เมตร แม้ตั้งอยู่บนโต๊ะหรือเปียโน ห้องลับเข้าถึงได้เฉพาะหลังปลดล็อก
- **ตัวละคร:** จุดทำงานและทุกช่วงของกิจวัตรสามจุดของ NPC หกคนไม่ตัดผ่านโต๊ะ เตียง เตา หรือกำแพง
- **ขอบเขต:** พื้นที่นอกบ้านไม่ถูกจัดเป็นห้อง การเดินทแยงไม่เพิ่มความเร็ว และเฟรมค้างไม่ทำให้ตัวละครพุ่งข้ามกำแพง
- **ความสอดคล้อง:** การทดสอบค้นเส้นทางจากจุดเข้าสู่ทุกห้องทุกชั้น ตรวจประตู จุดเกิด บันได หลักฐาน และการล็อกห้องลับจากข้อมูลที่ใช้สร้างฉาก
- **เนื้อเรื่อง:** 11 ผู้ตาย = มีรา + แขกผู้ใหญ่สิบคน; นารารอด หลักฐานยัง 14 ชิ้น ความทรงจำ 6 ชุด ตอนจบ 3 แบบ ผังใหม่ไม่เปลี่ยนข้อเท็จจริงนี้

การทดสอบโค้ดยืนยันการเดินและกติกา ไม่แทนการลองเล่นกับผู้ใช้จริงเพื่อประเมินกล้อง ความชัดเจนของภาพและความลื่นบนโทรศัพท์

## ทางไปสู่งานศิลป์สำหรับการผลิต

ฉากปัจจุบันสร้างด้วยโค้ด มีวัสดุ CC0 ที่เก็บไว้ในเกม และตัวละคร Kenney ที่มีใบอนุญาต ไม่ต้องติดตั้งโปรแกรมเพิ่มเพื่อเล่นหรือรันเว็บด้วย Node.js

งานถัดไปที่เหมาะกับ **Blender** คือสร้างชุดสถาปัตยกรรมและเฟอร์นิเจอร์เฉพาะเรื่องจากผังที่ผ่านการเล่นแล้ว จากนั้นทำ UV, bake รายละเอียด, export เป็น glTF/GLB, ลดรายละเอียดระยะไกล และวัดหน่วยความจำ/จำนวน draw call บนเครื่องเป้าหมาย การผลิตตัวละครเฉพาะคนต้องเพิ่ม rig และ animation ส่วนเสียงพากย์กับภาพยนตร์ตอนจบต้องมีขั้นตอนบันทึกและกำกับแยก ไม่ได้รวมว่าเสร็จแล้วใน rc.5

ก่อนแทนฉาก procedural ด้วยโมเดลใหม่ ให้คงประตู ขนาดทางเดิน จุดตรวจหลักฐาน และกิจวัตรที่ทดสอบได้ไว้ งานศิลป์ควรเพิ่มรายละเอียดและเอกลักษณ์โดยไม่ทำให้เส้นทางที่ผู้เล่นเรียนรู้เปลี่ยนโดยไม่มีเหตุผล
