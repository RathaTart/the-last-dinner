# ผังคฤหาสน์และมาตรฐานฉาก — rc.6

บ้านที่ผู้เล่นอ่านทางได้ มีเหตุผลว่าจะใช้แต่ละพื้นที่อย่างไร และมีรายละเอียดที่ช่วยสืบคดี คือเป้าหมายของผังนี้ ภาพใช้ตัวละครแบบ stylized กับฉาก Three.js บนเว็บ งานรอบนี้เพิ่มความสมจริงของพื้นที่และวัสดุ ส่วนโมเดลเฉพาะเกม งานเสียง และการทดสอบผู้เล่นเป็นขั้นผลิตถัดไป

## ขนาดและแหล่งข้อมูลเดียว

พื้นที่แต่ละระดับประมาณ **24 × 19 เมตร**; x ตั้งแต่ −12 ถึง +12, z ตั้งแต่ −9.5 ถึง +9.5 ประตูหน้าอยู่ทาง +z ด้านหลังบ้านอยู่ทาง −z ชั้นล่างสูง 0 เมตร ชั้นสอง +4.4 และใต้ดิน −4.4 ผังนี้เป็นคฤหาสน์กว้าง ไม่ใช่บ้านพักขนาดเล็ก ขนาดระบุพื้นที่ผังรวมซึ่งยังไม่ได้หักผนังและช่องบันได

`mansion-layout.js` ระบุขอบเขต 14 ห้อง ผนัง ประตู เฟอร์นิเจอร์ ตำแหน่งหลักฐาน จุดเกิด กิจวัตร NPC และพื้นผิวบันไดที่มีความสูงต่อเนื่อง `navigation.js` ใช้ข้อมูลชุดนี้ตรวจ collision และคำนวณความสูงผู้เล่น; `mansion-environment.js` ใช้สร้างฉากกับขั้นบันได ประตูจึงเป็นช่องจริงในผนัง และเส้นทางขึ้นลงตรงกับสิ่งที่เห็น

## ทางสัญจรที่อธิบายเรื่องได้

เส้นทางรับแขกคือ **ประตูหน้า → โถงรับแขก → โถงใหญ่ → ห้องอาหารหรือห้องดนตรี** ส่วนห้องงานกับครัวอยู่ปีกหลัง ประตูเสิร์ฟระหว่างครัวกับห้องอาหารช่วยให้กิจวัตรแม่ครัวมีเหตุผล แทนการพาอาหารผ่านโต๊ะช่าง

**บันไดใหญ่** เชื่อมโถงใหญ่กับชานพักชั้นสอง **บันไดรับใช้** เชื่อมครัวกับโถงใต้ดิน ตำแหน่งทั้งสองแยกกันให้ผู้เล่นรู้ว่ากำลังเข้าเขตบ้านหรือเขตบริการ ผู้เล่นเดินบนช่วงบันไดและชานเลี้ยวจริงด้วย WASD/ลูกศร ความสูงเปลี่ยนตามพื้นผิวอย่างต่อเนื่อง ไม่ต้องกดปุ่มเปลี่ยนชั้น กล้องตามความสูงและแสดงระดับที่เชื่อมกันระหว่างเดิน

## เส้นทางบันไดและช่องพื้น

บันไดทั้งสองเป็นแบบหักกลับสองช่วง มีชานเลี้ยวด้านหลัง แต่ละช่วงวิ่งในแนว z ยาว 3.15 เมตรและเปลี่ยนความสูง 2.2 เมตร ทางกลับใช้พื้นผิวเดิม ความเร็วคำนวณจากระยะสามมิติ จึงไม่เร่งขึ้นเพียงเพราะเดินบนทางลาด

| เส้นทาง | ช่วงแรก | ชานเลี้ยว | ช่วงที่สอง / จุดออก |
|---|---|---|---|
| บันไดใหญ่ขึ้น | ฝั่งตะวันตก x=−1.3 จาก z=−5.5 ไป −8.65 สูง 0 → +2.2 ม.; กว้าง 2.05 ม. | สูง +2.2 ม., x=−2.35 ถึง +2.35, z=−9.35 ถึง −8.65 | ฝั่งตะวันออก x=+1.3 กลับไป z=−5.5 สูง +2.2 → +4.4 ม.; ออกชานพักแถว z=−5.05 |
| บันไดรับใช้ลง | ฝั่งครัว x=−3.8 จาก z=−5.5 ไป −8.65 สูง 0 → −2.2 ม.; กว้าง 1.4 ม. | สูง −2.2 ม., x=−4.5 ถึง −0.3, z=−9.35 ถึง −8.65 | ฝั่งโถงใต้ดิน x=−1 กลับไป z=−5.5 สูง −2.2 → −4.4 ม.; ออกโถงแถว z=−5.05 |

ช่องบันไดใหญ่บนชั้นสองอยู่ประมาณ x=−2.55 ถึง +2.55, z=−9.4 ถึง −5.5 ช่องบันไดครัวอยู่ x=−4.5 ถึง −3.1, z=−9.35 ถึง −5.5 พื้นและฐานพื้นถูกเว้นจริงตามช่อง ทางเดินผู้เล่นจำกัดอยู่บนช่วงบันได ชานเลี้ยว และพื้นระดับเดียวกัน ขอบด้านข้างจึงไม่ปล่อยให้เดินกลางอากาศหรือเข้าช่วงบนจากพื้นข้างใต้

ทางเลี้ยวบันไดรับใช้ผ่านช่องผนังด้านหลังที่ x=−2.8 ใต้บ้าน ช่องนี้ไม่มีคานประตูเตี้ยขวางศีรษะบนชานยกสูง เคาน์เตอร์และอ่างครัวอยู่ฝั่งตะวันตกของช่องพื้น ไม่ทับขั้นลง

## การควบคุมกับกระเป๋านักสืบ

WASD/ลูกศรเดินสัมพันธ์กับกล้อง กด **Shift ค้างเพื่อวิ่ง** และกด **C เพื่อย่อหรือยืน** ความเร็วเดิน 2.3 เมตร/วินาที วิ่ง 4.3 และเดินขณะย่อ 1.15 ค่าเดียวกันใช้ตามระยะทางลาดสามมิติ ถ้ายังย่ออยู่ การกดวิ่งไม่เปลี่ยนเป็นท่ายืน บนมือถือกดค้างลูกศรกับปุ่มวิ่ง และแตะปุ่มย่อ

ระหว่างสำรวจ ฉากใช้พื้นที่หน้าต่างเต็มขึ้น รายการเวลา หลักฐาน ความคืบหน้า การตั้งค่า และคำใบ้อยู่ใน **กระเป๋านักสืบ** เปิดด้วยไอคอนกระเป๋าหรือ I/B/Tab; M เปิดแผนที่ ปิดด้วย Escape หรือปุ่มกลับไปเล่น ภายในหน้าต่าง Tab/Enter ใช้เลือกปุ่ม การเปิดกระเป๋าปล่อยปุ่มเดินและหยุดกิจวัตร NPC ชั่วคราว ผู้เล่นต้องกดเดินใหม่เมื่อปิด กระเป๋าเป็นหน้าต่างของเกม ไม่ต้องใช้โหมดเต็มจอของระบบปฏิบัติการ

E ใช้คุย ตรวจของ และเปิดแบบฟอร์มผนังลับเมื่ออยู่ใกล้ การเปิดแผนที่หรือกระเป๋าไม่ย้ายตำแหน่งตัวละคร ความทรงจำยังเป็นฉากสังเกตที่เลือกช่วง แล้วเปิดกระเป๋าเพื่อเทียบหลักฐานหรือแก้ปริศนา ไม่เปลี่ยนเป็นฉากเดินอิสระ

ห้องลับมีประตูเดียวทางห้องเตา ไม่มีช่องผ่านจากโถงใต้ดิน การเปิดต้องอาศัยคำให้การสองคนและรหัส เป็นการเปลี่ยนทางเข้าของฉากจริง ไม่ใช่เพียงเปิดบัตรหลักฐานใน UI คำตอบผิดแก้ได้และไม่ลบหลักฐาน

## มาตรฐานที่ตรวจได้

- **ทางเดิน:** ประตูห้องทั่วไปกว้าง 1.8–2.8 เมตร ช่องผนังสำหรับทางเลี้ยวบันไดรับใช้กว้าง 1.6 เมตร; รัศมีตัวผู้เล่น 0.2 เมตร ขนาดนี้เป็นหน่วยเล่นเกม ไม่ใช่การรับรองแบบก่อสร้าง
- **หลักฐาน:** ของจริงทั้งแปดจุดมีเส้นทางเข้าใกล้ระยะโต้ตอบ 1.65 เมตร แม้ตั้งอยู่บนโต๊ะหรือเปียโน ห้องลับเข้าถึงได้เฉพาะหลังปลดล็อก
- **ตัวละคร:** จุดทำงานและทุกช่วงของกิจวัตรสามจุดของ NPC หกคนไม่ตัดผ่านโต๊ะ เตียง เตา หรือกำแพง
- **ขอบเขต:** พื้นที่นอกบ้านไม่ถูกจัดเป็นห้อง การเดินทแยงไม่เพิ่มความเร็ว และเฟรมค้างไม่ทำให้ตัวละครพุ่งข้ามกำแพง
- **บันได:** ทดสอบขึ้นลงทั้งสองเส้นทาง รวมการเลี้ยวบนชาน ความสูงกลางทาง ระยะเดินสามมิติ การวิ่ง/ย่อ ขอบช่องพื้น และการเข้าช่วงบันไดจากความสูงผิด ระดับชั้นเปลี่ยนเมื่อถึงความสูงของปลายทาง
- **ความสอดคล้อง:** การทดสอบค้นเส้นทางจากจุดเข้าสู่ทุกห้องทุกชั้น ตรวจประตู จุดเกิด บันได หลักฐาน และการล็อกห้องลับจากข้อมูลที่ใช้สร้างฉาก
- **เนื้อเรื่อง:** 11 ผู้ตาย = มีรา + แขกผู้ใหญ่สิบคน; นารารอด หลักฐานยัง 14 ชิ้น ความทรงจำ 6 ชุด ตอนจบ 3 แบบ ผังใหม่ไม่เปลี่ยนข้อเท็จจริงนี้

การทดสอบโค้ดยืนยันการเดินและกติกา ไม่แทนการลองเล่นกับผู้ใช้จริงเพื่อประเมินกล้อง ความชัดเจนของภาพและความลื่นบนโทรศัพท์

## ทางไปสู่งานศิลป์สำหรับการผลิต

ฉากปัจจุบันสร้างด้วยโค้ด มีวัสดุ CC0 ที่เก็บไว้ในเกม และตัวละคร Kenney ที่มีใบอนุญาต ไม่ต้องติดตั้งโปรแกรมเพิ่มเพื่อเล่นหรือรันเว็บด้วย Node.js

งานถัดไปที่เหมาะกับ **Blender** คือสร้างชุดสถาปัตยกรรมและเฟอร์นิเจอร์เฉพาะเรื่องจากผังที่ผ่านการเล่นแล้ว จากนั้นทำ UV, bake รายละเอียด, export เป็น glTF/GLB, ลดรายละเอียดระยะไกล และวัดหน่วยความจำ/จำนวน draw call บนเครื่องเป้าหมาย การผลิตตัวละครเฉพาะคนต้องเพิ่ม rig และ animation ส่วนเสียงพากย์กับภาพยนตร์ตอนจบต้องมีขั้นตอนบันทึกและกำกับแยก ไม่ได้รวมว่าเสร็จแล้วใน rc.6

ก่อนแทนฉาก procedural ด้วยโมเดลใหม่ ให้คงประตู ขนาดทางเดิน จุดตรวจหลักฐาน และกิจวัตรที่ทดสอบได้ไว้ งานศิลป์ควรเพิ่มรายละเอียดและเอกลักษณ์โดยไม่ทำให้เส้นทางที่ผู้เล่นเรียนรู้เปลี่ยนโดยไม่มีเหตุผล
