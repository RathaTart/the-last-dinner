# คืนสังหารใต้เสียงระฆัง — Story Bible (มีเฉลย)

ฉบับ rc.5 · 1 ตุลาคม 2026 · case ID `hollow-bell`

บ้านเก็บหลักฐานการฆาตกรรมหมู่ ผู้คนเก็บความทรงจำที่ช่วยให้ตนทนอยู่ต่อได้ ผู้เล่นแก้เหตุการณ์ด้วยการเทียบคำให้การกับของจริง และต้องเลือกว่าจะส่งหลักฐานพร้อมคุ้มครองพยานหรือปล่อยความเงียบชนะอีกครั้ง

## เรื่องจริงที่เปลี่ยนไม่ได้

ห้าปีก่อน หมอศรัณย์จัดอาหารค่ำการกุศลเพื่อรวบรวมคนที่รู้เรื่องทุจริตและการทำร้ายผู้ป่วย เขาใช้สัญญาณฉุกเฉินให้แขกลงใต้บ้าน สั่งปิดห้อง และแก้ทะเบียนเพื่อปิดบังอาชญากรรม ก๊าซในห้องปิดทำให้แขกผู้ใหญ่สิบคนกับมีราเสียชีวิต นารารอดทางลอดก่อนเกิดเหตุสุดท้าย ไม่มีรายละเอียดสูตรหรือวิธีทำอาวุธในเกม

มีราขอกุญแจสำรอง ลงไปช่วย และพานาราออก เธอกลับไปช่วยคนที่เหลือ นาราเห็นแค่การกลับเข้าไป ไม่ได้เห็นการตาย แฟ้มต้นฉบับในห้องลับจึงเป็นหลักฐานที่ยืนยันชะตาของมีรา ความทรงจำเพียงอย่างเดียวไม่เฉลยคดี

คืนปัจจุบันก่อนขายบ้าน นักสืบได้รับกุญแจ รายชื่อสิบสองคน และเทปนิรนาม: สาม หนึ่ง สอง ผู้ส่งไม่ถูกเฉลยว่าเป็นมีรา ผู้ตายไม่กลับมามีชีวิตในตอนจบ

| เวลาจริง | เหตุการณ์ | หลักฐาน |
|---|---|---|
| 18:45 | ศรัณย์สั่งยาควบคุมโดยไม่มีคำสั่งรักษา | ใบรับของในความทรงจำลิน |
| 18:55 | ลินส่งซองให้มีรา | ใบรับของ / ความทรงจำลิน |
| 19:00 | เสิร์ฟอาหาร นาฬิกาเร็วหนึ่งชั่วโมงจึงตีแปด | สมุดครัว + ป้ายซ่อม |
| 19:05 | อรุณปิดประตูตามคำสั่งหมอ มีราขอให้เปิด | ความทรงจำอรุณ |
| 19:10 | หมอเปลี่ยนหน้าทะเบียน | ลายเซ็น / ความทรงจำหมอ |
| 19:20 | มีราขอกุญแจสำรองแล้วลงไปช่วย | ความทรงจำป้าละไม |
| 19:25 | สมชายลงคานด้านนอก แขกเปิดเองไม่ได้ | แบบประตู + ความทรงจำสมชาย |
| 19:30 | มีราพานาราออกทางลอด แล้วกลับไป | ความทรงจำนารา / รหัส 312 |
| 19:40 | ทะเบียนภายในบันทึกตายสิบเอ็ดคน | คำสั่งต้นฉบับและรายชื่อผู้ตาย |

สิบสองชื่อ = แขกสิบคน + มีรา + นารา เป็นทะเบียนเข้า ไม่ใช่รายชื่อผู้ตาย ทั้งหมดเป็นผู้ใหญ่ บุคคลอื่นในบ้านไม่ถูกนับเป็นเหยื่อในห้องปิด

## หกคนในบ้าน

| NPC | หน้าที่ปัจจุบัน / ห้อง | สิ่งที่ต้องนำให้ดู | สิ่งที่ความทรงจำพิสูจน์ |
|---|---|---|---|
| อรุณ | ช่างนาฬิกา / ห้องนาฬิกา | ป้ายซ่อม | เวลาที่ผิดและคำสั่งหมอ |
| ป้าละไม | แม่ครัว / ครัว | สมุดเสิร์ฟ | มีราลงไปช่วย ไม่ใช่หนี |
| ลิน | ดูสมุดเพลง / ห้องดนตรี | คำเตือน | ผู้สั่งของคือหมอ ไม่ใช่คนถือซอง |
| ศรัณย์ | ดูทะเบียน / ห้องพยาบาลชั้นสอง | ทะเบียนขาดหน้า | เขาแก้เอกสาร ยังไม่ใช่คำรับสารภาพฆ่า |
| สมชาย | ดูประตูและเตา / ใต้ดิน | บันทึกประตู | คานอยู่ด้านนอกตามคำสั่ง |
| นารา | เก็บภาพและเฝ้าทางออก / ห้องพักชั้นสอง | ภาพที่ขีดไว้ | ทางลอดและเสียง 312 ไม่มีภาพหลังเธอออก |

NPC ทำกิจวัตรสามจุดในห้องตนเอง ไม่ข้ามชั้นเอง การหยุดเวลาหยุด NPC แต่ผู้เล่นยังเดินได้ นาราไม่ถูกบังคับให้ลงใต้ดิน

## บ้านและทางเดินที่สัมพันธ์กับเรื่อง

คฤหาสน์มีพื้นที่ประมาณ 24 × 19 เมตรต่อชั้น รวม 14 พื้นที่ที่เกมนับเป็นห้อง ทั้งสามระดับอยู่ที่ความสูง 0, +4.4 และ −4.4 เมตร ผังใหม่นี้เปลี่ยนการเดินและการจัดฉาก ไม่เปลี่ยนผู้กระทำ เหตุการณ์ ผู้รอดชีวิต หรือจำนวนหลักฐาน

- **ชั้นล่าง — 6 ห้อง:** โถงรับแขก, โถงใหญ่, ห้องอาหาร, ครัว, ห้องนาฬิกา และห้องดนตรี นักสืบเข้าทางโถงรับแขกก่อนถึงโถงใหญ่ ห้องอาหารเชื่อมครัวด้วยประตูเสิร์ฟ; ห้องทำงานอยู่ปีกหลัง ส่วนพื้นที่รับแขกอยู่ปีกหน้า
- **ชั้นสอง — 4 ห้อง:** ชานพักบันได, ห้องพักแขก, ห้องพยาบาล และโถงภาพเหมือน บันไดใหญ่จากโถงกลางขึ้นชานพัก แล้วจึงแยกเข้าห้องส่วนตัว นารามีทางออกสู่พื้นที่กลางโดยไม่ต้องผ่านห้องหมอ
- **ใต้ดิน — 4 ห้อง:** โถงใต้ดิน, ห้องเก็บศพเก่า, ห้องเตา และห้องลับ บันไดคนรับใช้จากครัวลงโถงใต้ดิน โถงเชื่อมห้องเก็บศพกับห้องเตา แต่ไม่มีประตูเข้าห้องลับ ห้องลับเข้าทางผนังในห้องเตาหลังพิสูจน์ `lock` + `tunnel` และใส่รหัสเท่านั้น

หน้าที่ของเฟอร์นิเจอร์ช่วยเล่าเรื่อง: โต๊ะอาหารยังมีที่นั่งครบ สมุดอยู่บนโต๊ะเตรียมอาหาร ป้ายซ่อมติดนาฬิกาที่ยืนแยกจากโต๊ะ เอกสารหมออยู่บนโต๊ะทะเบียน สมุดประตูอยู่โต๊ะช่างเตา และแฟ้มสุดท้ายอยู่ในห้องเก็บต้นฉบับ ทุกชิ้นมีพื้นที่ให้เดินเข้าไปตรวจ ไม่ใช้ตำแหน่งกึ่งกลางห้องแทนความหมาย

ประตูและผนังที่เห็นใช้ข้อมูลชุดเดียวกับ collision การสำรวจจึงไม่ต้องเดาว่าช่องใดเดินทะลุได้ อ่านผังและเหตุผลการจัดพื้นที่ใน [MANSION-DESIGN.md](MANSION-DESIGN.md)

## ปริศนาและจุดจบ

มี 14 หลักฐาน: สิ่งของ 7, ความทรงจำ 6, แฟ้มสุดท้าย 1 ทุกความทรงจำมีสามช่วง ช่วงที่สองต้องตอบการสังเกตก่อนบันทึกได้ ห้องลับต้องมี `lock` กับ `tunnel` และใส่ 312 การตอบผิดไม่ทำลายหลักฐาน

หลังครบ 14 ชิ้น ผู้เล่นเรียงแปดเหตุการณ์หลัก แก้เวลาโดยป้ายซ่อม และระบุผู้สั่งด้วยใบรับของ ข้อสรุป: ศรัณย์ลงชื่อ / ฆาตกรรมเพื่อปกปิด / มีรากลับไปช่วย จากนั้นเตรียมคำให้การอรุณ เก็บต้นฉบับกับลิน และคุ้มครองนารากับป้าละไม

- **รุ่งเช้าที่คืนชื่อให้ผู้ตาย:** เตรียมครบสามอย่าง ส่งหลักฐานพร้อมคุ้มครองพยาน คดีเปิดใหม่และพบผู้ตาย เสียงระฆังสิบเอ็ดครั้งเงียบลง เป็นความยุติธรรม ไม่ใช่การคืนชีพ
- **แฟ้มที่ออกจากบ้าน:** มีคำให้การกับต้นฉบับ แต่ความปลอดภัยนารายังไม่เสร็จ ความจริงรอด ความยุติธรรมยังไม่จบ
- **อาหารค่ำครั้งต่อไป:** ปิดแฟ้มและปล่อยผู้มีอำนาจจัดการ บ้านถูกขาย เอกสารถูกฝังต่อ จานเพิ่มหนึ่งใบและเสียงเคาะกลับมา แม้ผู้เล่นเคยเปิดทางเข้าแล้ว ผู้สืบสวนคนต่อไปยังไม่ได้รับหลักฐาน

## AI และการบันทึก

AI ใช้คุยเรื่องความรู้สึกและตีความคำถาม ภาษาไทยเลือกธีมแล้วใช้บทที่ตรวจไว้ ภาษาอังกฤษสร้างประโยคจากข้อเท็จจริงที่เปิดเผยและผ่านตัวกรอง คำถามเรื่องฆาตกรรม เวลา ประตู ยา รหัส และชะตาตัวละครใช้บทแต่งที่ถูกล็อกตามหลักฐาน AI เปลี่ยน trust, สิ่งของ, รหัส หรือจุดจบไม่ได้
